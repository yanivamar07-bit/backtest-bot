## Objectif : 100/150 en 30 jours

### Structure de l'examen YAEL

Le YAEL (יע"ל – יידע עברית לאקדמיה ולחיים) comporte 4 sections :

| Section | Contenu | Points |
|---|---|---|
| **א** | Vocabulaire — synonymes, antonymes, définitions | ~40 pts |
| **ב** | Complétion de texte — choisir le bon mot | ~35 pts |
| **ג** | Compréhension écrite — questions sur textes | ~45 pts |
| **ד** | Expression écrite — rédaction guidée | ~30 pts |
| **Total** | | **150 pts** |

> **Stratégie prioritaire** : pour atteindre 100, viser 35/40 en vocab, 30/35 en complétion, 35/45 en compréhension. La rédaction est un bonus.

## Comment utiliser ce programme

1. **Jour 1** : Fais d'abord le mini-test dans `01_evaluation_initiale.md`
2. **Quotidiennement** : Suis le plan de `02_programme_30_jours.md` (45–60 min/jour)
3. **Chaque vendredi** : Examen blanc complet dans `08_examens_blancs.md`
4. **Après chaque test** : Auto-analyse dans `09_analyse_erreurs.md`
5. **En continu** : Mémorise les fiches dans `10_fiches_revision.md`
