# Méthode pour Répondre Rapidement et Juste au YAEL

> **Objectif** : Finir chaque section avec 5 minutes de marge. La rapidité + la précision = le score maximum.

---

## Vue d'ensemble : Gestion du temps à l'examen

| Section | Temps alloué | Questions | Temps/question |
|---|---|---|---|
| **A** — Vocabulaire | 30 min | 30 questions | ~1 min |
| **B** — Complétion | 25 min | 20 questions | ~1.25 min |
| **C** — Compréhension | 35 min | 25 questions | ~1.4 min |
| **D** — Rédaction | 30 min | 1 texte | Tout le temps |
| **Total** | **120 min** | | |

> **Règle d'or** : Si une question prend plus de 2 minutes → passer. Revenir à la fin.

---

## SECTION A — Vocabulaire : La méthode des 4 étapes

### Étape 1 : Lire le mot souligné (5 sec)
- Identifier la RACINE (שׁרש) du mot
- Chercher des mots de la même famille que tu connais

### Étape 2 : Chercher dans ta mémoire (10 sec)
- Le sens te vient ? Choisis ta réponse sans hésiter
- Le sens est flou ? Continue à l'étape 3

### Étape 3 : Éliminer (15 sec)
Technique d'ÉLIMINATION :
- Éliminer les réponses clairement fausses (souvent 2 sur 4)
- Choisir parmi les 2 restantes

### Étape 4 : L'instinct (5 sec)
- Si encore incertain → choisir la réponse qui "sonne" le mieux
- Ne JAMAIS laisser une case vide → toujours cocher quelque chose

---

### Astuces spécifiques Section A

**Reconnaître les synonymes par la racine :**
- לבחון / לבדוק / לבחור → même famille d'idée (examiner/vérifier/choisir)
- Si le mot de la question a une racine connue, cherche-la dans les options

**Les pièges classiques :**
1. Deux réponses proches → chercher LA PLUS PROCHE, pas juste "proche"
2. Le mot en hébreu biblique vs hébreu moderne → le YAEL teste l'hébreu moderne
3. Les faux amis : לחשוב (penser) ≠ לחשב (calculer)

**Les 5 familles de racines les plus testées :**
| Racine | Mots dérivés |
|---|---|
| כ-ת-ב | כתב / כתיבה / מכתב / כתוב |
| ד-ב-ר | דיבר / דיבור / מדבר / דברים |
| ל-מ-ד | למד / לימוד / מלמד / לומד |
| ש-נ-ה | שינה / שינוי / שונה / לשנות |
| ה-ב-ן | הבין / הבנה / מובן / להבין |

## SECTION B — Complétion de texte : La méthode du contexte

### Étape 1 : Lire la PHRASE ENTIÈRE (10 sec)
- Comprendre le sens global avant de regarder les options
- Repérer les mots autour du trou : ils donnent des indices

### Étape 2 : Anticiper (5 sec)
- Avant de regarder les options, essayer de deviner mentalement le type de mot manquant :
  - Verbe conjugué ? (quel temps ?)
  - Connecteur ?
  - Nom ?
  - Adjectif ?

### Étape 3 : Tester chaque option (20 sec)
- Insérer chaque option dans la phrase
- Lire à voix basse → ça "sonne" correctement ?

### Étape 4 : Accords grammaticaux (10 sec)
- Vérifier l'accord en genre (זכר/נקבה) et en nombre (יחיד/רבים)
- Vérifier le temps verbal (עבר/הווה/עתיד)

---

### Les 7 indices grammaticaux à repérer

1. **Sujet + verbe** : si le sujet est נקבה, le verbe doit être נקבה
   - היא _______ ← forcément verbe féminin
   
2. **Connecteur de cause/conséquence** : chercher la logique dans la phrase
   - X, _______ Y → si X cause Y → לכן
   - X _______ Y → si Y malgré X → עם זאת / אבל

3. **Préposition qui suit** : certains verbes exigent une préposition spécifique
   - התמקד **ב** → se concentrer SUR
   - תמך **ב** → soutenir

4. **Temps cohérent** : si la phrase a d'autres verbes, rester au même temps

5. **Mots de degré** : plus/moins/très → adjectif ou adverbe attendu

6. **Articles définis** : ה en hébreu est fusionné avec la préposition
   - ב + ה = ב**ּ** → dans LE

7. **Pluriel** : si le contexte implique plusieurs éléments → forme plurielle

## SECTION C — Compréhension : La méthode QTRA

### Q — Questions d'abord (2 min)
Lire TOUTES les questions AVANT de lire le texte.
- Souligner les mots-clés de chaque question
- Savoir quoi chercher = lire 2x plus vite

### T — Texte : survol rapide (2 min)
- Lire le TITRE + la PREMIÈRE phrase de chaque paragraphe
- Identifier la structure : introduction / développement / conclusion
- Repérer les chiffres, noms propres, connecteurs

### R — Réponses : chercher et ancrer (temps restant)
- Aller chercher la réponse dans le texte (ne pas deviner de mémoire !)
- Underline la ligne du texte qui répond à la question
- La réponse DOIT être dans le texte, pas dans ta tête

### A — Analyse des pièges
Les 5 types de pièges dans les questions de compréhension :

| Piège | Description | Comment éviter |
|---|---|---|
| **Trop général** | Une option résume tout le texte → pas forcément la bonne | Relire la question exacte |
| **Trop spécifique** | Une option cite un détail hors sujet | Revenir à la question générale |
| **Inverser** | Une option inverse le sens du texte | Vérifier les négations |
| **Hors texte** | Une option vraie mais non mentionnée dans le texte | Tout doit être dans le texte |
| **Presque vrai** | Une option proche mais avec un mot qui change tout | Comparer mot à mot |

---

### Types de questions et stratégies

**1. Question sur le sujet principal (נושא מרכזי)**
→ Lire le premier et le dernier paragraphe
→ La bonne réponse = ce qui englobe TOUT le texte

**2. Question sur un détail (פרט)**
→ Retourner dans le texte, trouver l'endroit exact
→ Ne pas répondre de mémoire

**3. Question sur le sens d'un mot (משמעות מילה)**
→ Lire les 2 phrases autour du mot
→ Remplacer le mot par chaque option → laquelle conserve le sens ?

**4. Question d'inférence (מה ניתן להסיק)**
→ La réponse N'EST PAS citée mot à mot dans le texte
→ Chercher la conclusion logique des informations données

**5. Question sur l'attitude de l'auteur (עמדת הכותב)**
→ Chercher les adjectifs évaluatifs et les connecteurs d'opposition
→ L'auteur est-il positif ? Négatif ? Neutre ? Ambivalent ?

## SECTION D — Rédaction : La méthode des 3 minutes de planification

**Avant d'écrire la moindre lettre : planifier 3 minutes**

### Schéma de planification rapide

```
SUJET : ____________________

POSITION : pour / contre / nuancée

Argument 1 : ______________
Exemple : _________________

Argument 2 : ______________
Exemple : _________________

Argument contre : __________
Réfutation : _______________

Conclusion : _______________
```

**Modèle de texte YAEL (100 mots) :**

```
[פסקת פתיחה — 15 מילים]

[פסקת גוף 1 — 30 מילים]  
ראשית, _____. לדוגמה, _____.
לכן, _____.

[פסקת גוף 2 — 30 מילים]
שנית, _____. 
בנוסף, _____.

[פסקת מסקנה — 15 מילים]
לסיכום, _____. 
לפיכך, _____.
```

## Gestion du stress pendant l'examen

### Technique des 3 respirations
Si tu bloques sur une question :
1. Ferme les yeux 5 secondes
2. Inspire profondément 3 fois
3. Passe à la question suivante et reviens

### Priorité absolue
1. Répondre à toutes les questions (même au hasard pour les inconnues)
2. Vérifier les réponses évidentes
3. Retravailler les incertaines si le temps le permet

### Ne jamais changer une réponse... sauf si
- Tu as une raison LOGIQUE claire
- Tu te souviens d'une règle grammaticale précise
- Le changement n'est pas une panique de dernière minute
