# Fiches de Révision Synthétiques — À Mémoriser

> **Usage** : Imprimer, découper, ou recopier sur des fiches cartonnées. Réviser chaque soir 10 minutes. Ces fiches = ton "insurance policy" pour l'examen.

## FICHE 1 — Les 20 Connecteurs Incontournables

```
┌─────────────────────────────────────────┐
│           CONNECTEURS YAEL              │
├──────────┬──────────┬───────────────────┤
│ CAUSE    │ כי       │ parce que         │
│          │ בגלל     │ à cause de (+nom) │
│          │ מכיוון ש │ étant donné que   │
│          │ עקב      │ suite à (+nom)    │
├──────────┼──────────┼───────────────────┤
│ CONSÉ-   │ לכן      │ donc              │
│ QUENCE   │ לפיכך    │ par conséquent    │
│          │ כתוצאה   │ par conséquent    │
│          │ מכאן ש   │ d'où il ressort   │
├──────────┼──────────┼───────────────────┤
│ OPPO-    │ אבל      │ mais              │
│ SITION   │ אולם     │ mais (formel)     │
│          │ לעומת זאת│ en revanche       │
│          │ אך       │ mais/toutefois    │
├──────────┼──────────┼───────────────────┤
│ CONCES-  │ למרות    │ malgré (+nom)     │
│ SION     │ למרות ש  │ bien que (+verbe) │
│          │ עם זאת   │ cependant         │
│          │ אף על פי │ néanmoins         │
│          │ כן       │                   │
├──────────┼──────────┼───────────────────┤
│ ADDI-    │ בנוסף    │ de plus           │
│ TION     │ כמו כן   │ également         │
│          │ יתרה מכך │ qui plus est      │
└──────────┴──────────┴───────────────────┘
```

**PIÈGE N°1** : כי + VERBE / בגלל + NOM
- כי הגשם ירד ✓ / בגלל הגשם ✓
- כי הגשם ✗ / בגלל שׁהגשם ירד (formel)

**PIÈGE N°2** : למרות + NOM / למרות ש + VERBE
- למרות הקשיים ✓
- למרות שׁהיו קשיים ✓

## FICHE 2 — Stratégie Sections A et B (30 sec à mémoriser)

```
┌──────────────────────────────────────────┐
│       MÉTHODE SECTION A (Vocab)          │
│                                          │
│  1. LIS le mot souligné                  │
│  2. CHERCHE la racine (שׁרש)              │
│  3. ÉLIMINE 2 options fausses            │
│  4. CHOISIS entre les 2 restantes        │
│  5. JAMAIS laisser vide → deviner       │
│                                          │
│       MÉTHODE SECTION B (Complétion)     │
│                                          │
│  1. LIS la phrase ENTIÈRE               │
│  2. IDENTIFIE le type (connecteur/verbe) │
│  3. TESTE chaque option à voix basse     │
│  4. VÉRIFIE accord genre/nombre/temps    │
│  5. La bonne réponse "sonne" correcte    │
└──────────────────────────────────────────┘
```

## FICHE 3 — Méthode QTRA (Compréhension)

```
┌──────────────────────────────────────────┐
│      MÉTHODE QTRA — SECTION C            │
│                                          │
│  Q — QUESTIONS d'abord (2 min)           │
│      Lire TOUTES les questions           │
│      Souligner les mots-clés             │
│                                          │
│  T — TEXTE : survol (2 min)              │
│      Titre + 1ère phrase de chaque §     │
│      Repérer chiffres et noms propres    │
│                                          │
│  R — RÉPONSES : chercher dans texte      │
│      Trouver la LINE qui répond          │
│      Ne PAS répondre de mémoire          │
│                                          │
│  A — ANALYSER les pièges                 │
│      Trop général / Trop spécifique      │
│      Hors texte / Presque vrai           │
└──────────────────────────────────────────┘
```

## FICHE 4 — Structure de Rédaction SATC

```
┌──────────────────────────────────────────┐
│       RÉDACTION YAEL — FORMULE SATC      │
│                                          │
│  S — Sujet (פתיחה) : 15–20 מילים        │
│  "בעולם של היום, נושא ה___ הפך..."      │
│                                          │
│  A — Arguments (גוף) : 2×30 מילים       │
│  "ראשית, ___. לדוגמה, ___. לכן, ___."   │
│  "שנית, ___. בנוסף, ___."               │
│                                          │
│  T — Transition + concession             │
│  "מצד שני, ___. אמנם ___ אולם ___."     │
│                                          │
│  C — Conclusion (סיום) : 15–20 מילים    │
│  "לסיכום, ___. לאור זאת, עמדתי היא..." │
│                                          │
│  MINIMUM : 80 מילים | IDÉAL : 100–120   │
└──────────────────────────────────────────┘
```

## FICHE 12 — Les 20 Pièges à Éviter

```
Section A :
1. Ne pas confondre קיבל (reçu) et לקח (pris)
2. Ne pas confondre הרגיש (ressenti) et הבין (compris)
3. Ne pas prendre le 2ème mot "proche" → prendre le PLUS proche
4. Ne pas oublier de chercher la racine

Section B :
5. כי + verbe / בגלל + nom → ne pas mélanger
6. למרות + nom / למרות ש + verbe → ne pas mélanger
7. Vérifier le temps verbal (passé/présent/futur)
8. Vérifier l'accord (masculin/féminin/singulier/pluriel)

Section C :
9. Toujours lire les questions AVANT le texte
10. Ne jamais répondre de mémoire → tout est dans le texte
11. Méfier des options "vraies mais pas dans le texte"
12. Pour le "sujet principal" → chercher ce qui couvre TOUT
13. Pour "inférence" → la réponse doit découler logiquement
14. Ne pas dépasser 10 min par texte

Section D :
15. Texte de MOINS de 80 mots = pénalité
16. Pas de conclusion = pénalité
17. Répéter לכן 5 fois = mauvais score cohérence
18. Adjectifs non accordés = pénalité langue
19. Hors sujet = pénalité contenu
20. Pas de plan = texte décousu = -8 pts structure
```
