### Q1 — המשלחת **הגיעה** לוועידה הבינלאומית.
**✅ Réponse correcte : ב) הופיעה**

**Analyse du mot :** הגיעה = elle est arrivée (passé féminin de לְהַגִּיעַ)

| Option | Traduction | Pourquoi ✗ ou ✓ |
|---|---|---|
| א) עזבה | elle a quitté | ✗ Sens OPPOSÉ — quitter ≠ arriver |
| **ב) הופיעה** | **elle est apparue / s'est présentée** | **✓ Sens très proche de "arriver/se présenter à un lieu"** |
| ג) כישלה | elle a échoué | ✗ Aucun rapport avec se déplacer |
| ד) נסעה | elle a voyagé / est partie | ✗ Proche mais נסעה implique le trajet, pas l'arrivée |

> **Piège classique :** נסעה (voyager) semble proche de הגיעה (arriver), mais נסעה = le mouvement de départ, pas l'arrivée à destination.

### Q2 — הוא **אחראי** לתוצאות הפרויקט.
**✅ Réponse correcte : ב) ממונה על**

**Analyse du mot :** אחראי = responsable (adjectif masculin)

| Option | Traduction | Pourquoi ✗ ou ✓ |
|---|---|---|
| א) אשם | coupable | ✗ Être "coupable" ≠ être "responsable". אשם = blâme moral, אחראי = charge fonctionnelle |
| **ב) ממונה על** | **chargé de / en charge de** | **✓ Exactement le sens de responsable = en charge de** |
| ג) מודע | conscient | ✗ Savoir que quelque chose existe ≠ en être responsable |
| ד) זכאי | méritant / ayant droit | ✗ Droit à quelque chose ≠ responsabilité |

> **Nuance importante :** En hébreu, אשם (coupable) et אחראי (responsable) sont deux mots très différents. אחראי n'implique pas de faute, juste une charge.

### Q3 — הם **הצליחו** לשכנע את הצד השני.
**✅ Réponse correcte : ג) עלה בידם**

**Analyse du mot :** הצליחו = ils ont réussi (passé masculin pluriel de לְהַצְלִיחַ)

| Option | Traduction | Pourquoi ✗ ou ✓ |
|---|---|---|
| א) כישלו | ils ont échoué | ✗ Sens OPPOSÉ |
| ב) הגיעו | ils sont arrivés | ✗ Arriver ≠ réussir |
| **ג) עלה בידם** | **ils ont réussi à (litt. "ça leur a monté entre les mains")** | **✓ Expression idiomatique exacte = réussir** |
| ד) הסכימו | ils ont accepté / consenti | ✗ Accepter une proposition ≠ réussir à persuader |

> **À retenir :** עלה בידם est une expression idiomatique très fréquente au YAEL. Elle signifie exactement "ils ont réussi à" / "ils ont pu".

### Q4 — הדו"ח **מצביע** על עלייה מתמשכת.
**✅ Réponse correcte : ב) מראה**

**Analyse du mot :** מצביע = indique / pointe vers (présent de לְהַצְבִּיעַ)

| Option | Traduction | Pourquoi ✗ ou ✓ |
|---|---|---|
| א) מוכיח | prouve | ✗ מוכיח = prouver de façon certaine. מצביע = indiquer, suggérer, pas forcément prouver |
| **ב) מראה** | **montre / indique** | **✓ Très proche : montrer ≈ pointer vers = indiquer** |
| ג) מכחיש | nie | ✗ Sens OPPOSÉ |
| ד) מסביר | explique | ✗ Expliquer ≠ indiquer |

> **Nuance :** מוכיח (prouve) semble proche mais il y a une différence de certitude. מצביע = "indique/suggère", מוכיח = "prouve définitivement". La question cherche le synonyme le plus proche = מראה.

### Q5 — היא **מקיימת** פגישות שבועיות עם הצוות.

| Option | Traduction | Pourquoi ✗ ou ✓ |

| ב) מדגיש | souligne / accentue | ✗ Accentuer ≠ traiter un sujet |

### Q11 — ההחלטה **השפיעה** על כל הענף.
**✅ Réponse correcte : ב) שינתה**

**Analyse du mot :** השפיעה = elle a influencé / affecté (passé féminin de לְהַשְׁפִּיעַ)

| Option | Traduction | Pourquoi ✗ ou ✓ |
|---|---|---|
| א) פגעה | elle a blessé / nui | ✗ פגעה implique un effet NÉGATIF. השפיעה peut être neutre ou positif |
| **ב) שינתה** | **elle a changé** | **✓ Influencer = produire un changement = שינתה est la meilleure approximation** |
| ג) הפריעה | elle a dérangé | ✗ Déranger = effet négatif spécifique ≠ influencer en général |
| ד) שיפרה | elle a amélioré | ✗ Améliorer = effet positif seulement. השפיעה est neutre |

> **Clé :** השפיעה est neutre (peut être positif ou négatif). פגעה et שיפרה ont une valence spécifique. שינתה (changer) est le plus neutre et donc le plus proche.

> **Synonymes parfaits :** עיקרי = ראשי = principal/central. Racines différentes, sens identique. ד est trop fort (unique = seule et aucune autre).

### Q24 — הוא **שמר** על קשר טוב עם לקוחותיו.

### Q31 — חברות _______ לאמץ טכנולוגיות חדשות
**✅ Réponse : ב) נדרשות**

Le texte dit que les entreprises DOIVENT adopter des technologies = elles sont obligées.

| Option | Pourquoi ✗ ou ✓ |
|---|---|
| א) מסרבות (refusent) | ✗ Refuser + infinitif = elles ne veulent pas. Le contexte = elles DOIVENT |
| **ב) נדרשות (sont requises/obligées)** | **✓ נדרשות לאמץ = sont tenues d'adopter = logique dans le contexte concurrentiel** |
| ג) מצפות (s'attendent à) | ✗ S'attendre = attendre passivement. Or les entreprises agissent |
| ד) יכולות (peuvent) | ✗ Pouvoir = possibilité. Le contexte implique une obligation |

> **Indice grammatical :** נדרשות + לאמץ (infinitif) = "sont tenues de..." = structure d'obligation.

### Q32 — לאמץ טכנולוגיות חדשות _______ להישאר תחרותיות
**✅ Réponse : ג) כדי**

La phrase exprime un **but** : adopter des technologies AFIN DE rester compétitives.

| Option | Pourquoi ✗ ou ✓ |
|---|---|
| א) כי (parce que) | ✗ כי + verbe conjugué. Ici suit un infinitif להישאר |
| ב) למרות (malgré) | ✗ Malgré = concession, aucun sens ici |
| **ג) כדי (afin de)** | **✓ כדי + infinitif = afin de. But : adopter la techno POUR rester compétitif** |
| ד) לפני (avant) | ✗ Avant ≠ afin de |

> **Règle grammaticale :** כדי est toujours suivi d'un **infinitif** (להישאר, לעשות...). כי est suivi d'un **verbe conjugué**. Cette règle élimine כי.

### Q33 — _______, השינוי לא פשוט עבור כולם
**✅ Réponse : ג) עם זאת**

La phrase précédente dit que les entreprises DOIVENT s'adapter. La phrase suivante dit que ce n'est pas simple. C'est une **concession**.

| Option | Pourquoi ✗ ou ✓ |
|---|---|
| א) לכן (donc) | ✗ Donc = conséquence logique. Or passer de "obligation" à "difficile" n'est pas une conséquence directe |
| ב) כמו כן (également) | ✗ Également = ajouter quelque chose de similaire. Ici on introduit un contraste |
| **ג) עם זאת (cependant)** | **✓ עם זאת = connecteur de contraste/concession = parfait ici** |
| ד) בנוסף (de plus) | ✗ De plus = addition. Or la phrase suivante contraste avec la précédente |

> **Indice logique :** Chercher la relation entre les deux phrases. Avant : avantage/obligation. Après : difficulté. = **contraste** → עם זאת, אבל, אולם.

|---|---|
| א) שמחים על (sont contents de) | ✗ Être content d'une menace = contradiction |
| **ב) מרגישים (ressentent)** | **✓ מרגישים איום = ressentir une menace = naturel et logique** |
| ג) מציגים (présentent) | ✗ Présenter une menace ≠ la ressentir |

### Q35 — עובדים רבים מרגישים איום על מקום עבודתם _______ האוטומציה
**✅ Réponse : ב) עקב**

Les travailleurs ressentent une menace **à cause de** l'automatisation.

| Option | Pourquoi ✗ ou ✓ |
|---|---|
| א) כי (parce que) | ✗ כי + verbe conjugué. האוטומציה est un **nom**, donc כי ne peut pas le suivre directement |
| **ב) עקב (suite à / en raison de)** | **✓ עקב + nom = en raison de. עקב האוטומציה = en raison de l'automatisation** |
| ג) בגלל (à cause de) | ✗ Aussi correct grammaticalement ! Mais עקב est plus formel et plus précis dans ce contexte académique. בגלל peut aussi fonctionner, mais עקב est légèrement meilleur |
| ד) מכיוון שׁ (étant donné que) | ✗ מכיוון ש + verbe conjugué. Ici suit un nom |

> **Règle cruciale :** עקב / בגלל / בשל + **NOM** ; כי / מכיוון ש / מאחר ש + **VERBE CONJUGUÉ**

## Examen 1 — Sujet : אתגרי העלייה לישראל

### Exemple de rédaction niveau B (suffisant pour avoir 20/30)

> עולה חדש לישראל מתמודד עם אתגרים רבים. ראשית, קשיי השפה הם אתגר מרכזי. אף על פי שיש קורסי עברית, הלמידה לוקחת זמן רב ומקשה על השתלבות בעבודה ובחברה. שנית, הסתגלות תרבותית היא אתגר נוסף — הנורמות החברתיות בישראל שונות מאוד ממה שעולה חדש הכיר בארצו.
>
> עם זאת, ישנם פתרונות. כדי להתגבר על קשיי השפה, מומלץ ללמוד עברית עוד לפני העלייה ולהשתמש בה מדי יום. לגבי ההסתגלות התרבותית, חשוב להצטרף לקהילה מקומית.
>
> לסיכום, העלייה קשה אך אפשרית. בנחישות ובעזרת הסביבה, ניתן להשתלב בהצלחה.

**ניתוח הציון :**
| קריטריון | ציון | הסבר |
|---|---|---|
| מבנה | 7/8 | פתיחה + 2 גוף + מסקנה ✓ |
| תוכן | 8/9 | 2 אתגרים + 2 פתרונות ✓ |
| מחברים | 7/8 | ראשית / שנית / עם זאת / כדי / לסיכום ✓ |
| שפה | 4/5 | דקדוק טוב, כמה שגיאות קלות |
| **סה"כ** | **26/30** | ✓ |

### Exemple de rédaction niveau A (pour 27–30/30)

> כעולה חדש לישראל, ידוע לי שהאתגרים רבים ומגוונים. ראשית, מחסום השפה הוא הקשה מכולם. העברית שונה מכל שפה אירופאית, ולמידתה דורשת מאמץ מתמשך. לפיכך, מומלץ להתחיל ללמוד עברית לפחות שנה לפני העלייה ולהירשם לאולפן מיד עם הגעה.
>
> שנית, ההסתגלות הכלכלית מהווה אתגר לא פחות חשוב. שוק העבודה הישראלי דורש הסמכות ישראליות ומיומנויות ספציפיות. בנוסף, יוקר המחייה גבוה. כדי להתמודד עם כך, חשוב לחקור את שוק העבודה מראש ולמצוא מסגרת הכשרה מקצועית.
>
> לסיכום, אף על פי שהאתגרים גדולים, הם לא בלתי ניתנים להתגברות. בתכנון נכון ובתמיכת הקהילה, העלייה יכולה להיות חוויה מעשירה ומשמעותית.

**ניתוח :**
- מילים : ~130 ✓
- מחברים : לפיכך / שנית / בנוסף / כדי / לסיכום / אף על פי ✓ (6 מחברים שונים)

## Examen 2 — Sujet : הטכנולוגיה ופרטיות האדם

### Exemple corrigé (niveau A)

> שנית, פריצות סייבר חושפות מידע רגיש של מיליוני אנשים ללא הסכמתם. אולם, ניתן להפחית את הסיכון באמצעות סיסמאות חזקות, אימות דו-שלבי וחינוך דיגיטלי.
>
> לסיכום, הטכנולוגיה מציבה אתגרים אמיתיים לפרטיות, אולם עם חקיקה מתאימה ומודעות אישית, ניתן ליהנות מהיתרונות הדיגיטליים מבלי לוותר על הפרטיות.

# RÉCAPITULATIF — Les 15 Pièges les Plus Fréquents

| # | Piège | Exemple | Solution |
|---|---|---|---|
| 1 | Synonyme vs Même mot | מצביע ≠ מוכיח | Vérifier le degré de certitude |
| 2 | כי vs בגלל | כי + verbe / בגלל + nom | Tester avec la suite |
| 3 | Positif vs Négatif | השפיעה ≠ פגעה | Vérifier la valence |
| 4 | Résultat vs Processus | מצאה ≠ חיפשה | Chercher = pas encore trouvé |
| 5 | Temporaire vs Définitif | הוקפא ≠ בוטל | Geler = temporaire |
| 6 | Obligation vs Possibilité | מחייב ≠ מאפשר | Obligation = plus fort |
